# Getting help

- **How do I…?** Start with the [README](README.md): download guide, first-launch warnings, wake tips.
- **Something is broken:** open a [bug report](https://github.com/ugurpm/NapPilot/issues/new?template=bug_report.yml).
  In the app, **Settings → About → Report a bug** opens the same form.
- **I have an idea:** open a [feature request](https://github.com/ugurpm/NapPilot/issues/new?template=feature_request.yml).
- **Security problem:** report it privately, see [SECURITY.md](SECURITY.md).
- **Anything else:** email **ugurpm@gmail.com**.

NapPilot is maintained in spare time, so replies can take a few days.
